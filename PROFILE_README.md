## 🚀 Key Projects

### 🛠️ [CodeWorkspace / CodeFlow](https://github.com/arpitambulkar27/codeflow) — Real-Time Collaborative Workspace & Code Execution Platform
`Node.js` • `Express.js` • `Socket.io` • `BullMQ` • `Redis` • `Docker (dockerode)` • `Monaco Editor` • `Gemini API` • `Prometheus`
* **Asynchronous Task Queue:** Engineered an asynchronous job processing pipeline using BullMQ and Redis, returning non-blocking `202 Accepted` responses (`<5ms` queue latency) to prevent HTTP thread blocking during heavy code execution spikes.
* **Container Security Sandbox:** Built a sandboxed execution engine using Docker (`dockerode`) across Python, JS, Java, and C++; enforced 128MB RAM caps, 0.5 CPU core limits, 64 PID caps, and an 8s timeout kill switch to prevent host resource exploitation and fork bombs.
* **Real-Time Collaboration:** Integrated Monaco Editor with WebSockets (`Socket.io`) to enable real-time code synchronization, live multi-user cursor position tracking, and active room participant management.
* **AI Diagnostics & Telemetry:** Integrated Google Gemini API (`@google/genai`) for automated syntax error diagnostics and complexity analysis; configured Prometheus metrics (`prom-client`) tracking HTTP request durations and active socket gauges.
