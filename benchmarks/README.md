# CodeFlow Performance Benchmarks

To execute load benchmarks against CodeFlow's code execution engine, ensure the backend server and its Redis-backed BullMQ execution worker are running (optionally setting `DISABLE_RUN_RATE_LIMIT=true` and `EXEC_CONCURRENCY=8` in `backend/.env` for testing). Install [k6](https://k6.io/) and execute any benchmark scenario by passing the target backend URL and an authenticated user JWT via environment variables: `k6 run -e TARGET_URL=http://localhost:5000 -e BENCH_TOKEN=<your_jwt_token> benchmarks/bench_queued_python.js` (or `bench_queued_js.js` for JavaScript workloads, `bench_direct_sync.js` for synchronous execution baselines, or `warmup.js` / `warmup_python.js` for container pre-warming). The queued benchmark scripts dispatch code execution jobs to `POST /api/run`, track enqueue latency, poll `GET /api/run/status/:jobId` every 200ms until completion, and record end-to-end latency percentiles, throughput (jobs/sec), and timeout/error statistics.
